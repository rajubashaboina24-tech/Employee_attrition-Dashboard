# Employee_attrition-Dashboard
## Project Objective
To identify key factors influencing employee attrition and understand workforce trends across different departments, job levels, and locations.

## Dataset Used
<a href="https://github.com/rajubashaboina24-tech/Employee_attrition-Dashboard/blob/main/Employee%20attrition%20dataset.xlsx">Dataset</a>

## Qusetions (KPIs)
- What is the overall employee attrition rate.
- Which departments and job levels have the highest attrition.
- Which locations experience the highest employee turnover.
- How do salary and employee satisfaction vary across job levels and departments.

## Dashboard
<a href="https://github.com/rajubashaboina24-tech/Employee_attrition-Dashboard/blob/main/Employee%20attrition%20dashboard.png">Dashboard</a>

## Process
- Data Preparation – Collect, clean, transform, and prepare employee data for analysis.
- Analyze attrition, salary, satisfaction, promotions, departments, job levels, and locations using interactive Power BI visuals.
- Identify attrition patterns and workforce gaps to support effective employee retention and HR strategies.
